# NeuraDesk

دستیار دسکتاپ پایتون با رابط تیره، گفت‌وگوی ذخیره‌شونده و ابزارهای پردازش متن. نسخه فعلی کاملاً محلی است و برای اجرا به کتابخانه‌های جانبی نیاز ندارد.

## امکانات
- رابط گرافیکی با Tkinter
- چند گفت‌وگوی ذخیره‌شده در SQLite
- خروجی گرفتن از گفتگو به فایل TXT
- شمارش واژه‌ها، جمله‌ها و نویسه‌ها
- استخراج واژه‌های پرتکرار و خلاصه‌سازی استخراجی
- پاک‌سازی فاصله‌ها و علائم نگارشی
- محاسبه امن عبارت‌های ریاضی ساده (بدون `eval`)
- تست‌های خودکار با `unittest`

## پیش‌نیازها
- Python 3.10 یا جدیدتر (پیشنهاد: Python 3.12 یا 3.13)
- Tkinter. در نصب رسمی Python برای ویندوز معمولاً همراه پایتون نصب است.
- در زمان اجرا به اینترنت یا `pip install` نیاز نیست.

## اجرا در ویندوز
1. پوشه را از حالت فشرده خارج کن.
2. پوشه `NeuraDesk` را در VS Code باز کن.
3. از منوی `Terminal > New Terminal` ترمینال را باز کن.
4. نسخه پایتون را بررسی کن:
   ```powershell
   python --version
   ```
5. برنامه را اجرا کن:
   ```powershell
   python app.py
   ```
   اگر دستور بالا کار نکرد، امتحان کن:
   ```powershell
   py app.py
   ```

## اجرای تست‌ها
در ترمینال، از پوشه اصلی پروژه:
```powershell
python -m unittest discover -s tests -v
```
یا:
```powershell
py -m unittest discover -s tests -v
```

## محل ذخیره داده‌ها
پایگاه داده در مسیر زیر ساخته می‌شود:
- Windows: `%USERPROFILE%\\.neuradesk\\neuradesk.sqlite3`
- Linux/macOS: `~/.neuradesk/neuradesk.sqlite3`

برای پشتیبان‌گیری، برنامه را ببند و از فایل دیتابیس کپی بگیر.

## نکات مهم و محدودیت‌ها
- خلاصه‌ساز فعلی از روش استخراجی ساده استفاده می‌کند؛ جمله‌های متن اصلی را بر اساس فراوانی واژه‌ها انتخاب می‌کند و خلاصه انسانی یا درک معنایی عمیق تضمین نمی‌شود.
- بدون API، چت محلی پاسخ‌های محدود و قانون‌محور می‌دهد و یک مدل زبانی بزرگ نیست.
- برای فعال کردن چت هوشمند آنلاین، داخل برنامه روی «تنظیم هوش مصنوعی آنلاین» بزن و کلید API، آدرس پایه و نام مدل را وارد کن. کلید در این نسخه فقط تا بسته‌شدن برنامه در حافظه می‌ماند؛ آن را با کسی به اشتراک نگذار. API ممکن است هزینه داشته باشد.
- دکمه «فرستادن متن به چت» متن کادر ابزارها را بلافاصله به چت می‌فرستد. اگر کلید API تنظیم نشده باشد، پاسخ‌های آزاد محدود و قانون‌محورند و این برنامه به‌تنهایی یک مدل زبانی بزرگ نیست.
- روش جایگزین تنظیم از طریق متغیرهای محیطی نیز در پایین آمده است. کلید API را داخل کد یا GitHub قرار نده.
  - PowerShell (فقط برای پنجره ترمینال فعلی):
    ```powershell
    $env:NEURADESK_API_KEY="کلید-API-خودت"
    $env:NEURADESK_API_BASE_URL="https://api.openai.com/v1"
    $env:NEURADESK_MODEL="gpt-4o-mini"
    python app.py
    ```
  - برای سرویس‌های سازگار با API سبک OpenAI، مقدار `NEURADESK_API_BASE_URL` و نام مدل را طبق مستندات همان سرویس تغییر بده.
  - استفاده از API ممکن است هزینه داشته باشد و نیازمند اینترنت است. پیام‌های عادی به سرویس ارسال می‌شوند؛ متن حساس نفرست.
  - در این نسخه هر پیام به‌صورت مستقل به API ارسال می‌شود؛ سابقه گفتگو در دیتابیس ذخیره می‌شود اما هنوز به مدل آنلاین به‌عنوان زمینه مکالمه فرستاده نمی‌شود.
  - اگر API تنظیم نشده باشد یا درخواست آنلاین شکست بخورد، برنامه به پاسخ‌های محلی محدود برمی‌گردد.
- تشخیص واژه و جمله برای فارسی و انگلیسی تقریبی است و ممکن است در متن‌های خاص دقیق نباشد.
- داده‌های گفتگو روی همین دستگاه ذخیره می‌شوند. از وارد کردن اطلاعات حساس خودداری کن، مخصوصاً اگر دستگاه مشترک است.
- پروژه تست‌های پایه دارد، اما هیچ نرم‌افزاری را نمی‌توان بدون آزمون در محیط واقعی «بدون باگ» تضمین کرد.
